## PearlOS Documentation Hub

This folder centralizes all project documentation for the open source PearlOS repository.

- **Architecture**: high-level system design and deep dives live in `architecture/`.
- **Setup**: all platform and install guides live in `setup/`.
- **Development**: contributor and testing docs live in `development/`.
- **Voice**: voice pipeline, TTS, and related guides live in `voice/`.
- **Operations**: deployment, cloud, and infrastructure plans live in `operations/`.
- **Planning**: roadmaps and implementation plans live in `planning/`.
- **Fixes**: postmortems and bug fix writeups live in `fixes/`.
- **Reports**: QA and version snapshots live in `reports/`.
- **AI**: editor/agent guidance and context live in `ai/`.
- **Guidelines**: product and engineering guidelines migrated from `conductor/` live in `guidelines/`.
- **Changelog**: [CHANGELOG.md](./CHANGELOG.md) tracks release history.
